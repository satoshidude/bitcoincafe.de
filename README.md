# BitcoinCafé

[BitcoinCafé](https://bitcoincafe.de) is a German-language Bitcoin community site built on Nostr and Lightning.

## Features

- Curated Bitcoin news and long-form articles
- Nostr login and profiles
- Comments and reactions published through Nostr
- Lightning zaps for articles
- Community discussions
- Bitcoin network information
- Installable progressive web app

The site is Bitcoin-only and does not require a traditional user account.
